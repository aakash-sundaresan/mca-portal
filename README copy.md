# MCA Portal - Document Upload System

A simple web application that allows users to upload documents locally, which are then stored in an AWS S3 bucket's `auditors-report/uploads/` folder. The application integrates with your existing pipeline that automatically processes uploaded documents and generates JSON metadata in the `auditors-report/json/` folder.

## Features

- **File Upload**: Drag and drop or click to upload documents
- **S3 Integration**: Automatic upload to AWS S3 bucket `auditors-report/uploads/` folder
- **Pipeline Integration**: Works with your existing processing pipeline
- **Real-time Status**: Live upload and pipeline processing status updates
- **JSON Display**: View JSON metadata generated by your pipeline from `auditors-report/json/` folder
- **Responsive UI**: Modern, mobile-friendly interface

## Setup Instructions

### 1. Install Dependencies

```bash
# Install all dependencies (root, backend, and frontend)
npm run install-all
```

### 2. Configure AWS S3

1. Copy the environment template:
   ```bash
   cp backend/env.example backend/.env
   ```

2. Edit `backend/.env` with your AWS credentials:
   ```env
   AWS_ACCESS_KEY_ID=your_access_key_here
   AWS_SECRET_ACCESS_KEY=your_secret_key_here
   AWS_REGION=us-east-1
   S3_BUCKET_NAME=your-bucket-name
   PORT=5000
   ```

3. Make sure your S3 bucket exists and your AWS credentials have the necessary permissions:
   - `s3:PutObject`
   - `s3:GetObject`
   - `s3:ListBucket`

### 3. Run the Application

```bash
# Start both backend and frontend concurrently
npm run dev
```

Or start them separately:

```bash
# Backend only (port 5000)
npm run server

# Frontend only (port 3000)
npm run client
```

### 4. Access the Application

- Frontend: http://localhost:3000
- Backend API: http://localhost:5000

## API Endpoints

### POST `/api/upload`
Upload a document to S3 and generate JSON metadata.

**Request**: Multipart form data with `document` field
**Response**: Upload ID and processing status

### GET `/api/status/:uploadId`
Get the current status of an upload.

**Response**: Upload status and metadata

### GET `/api/json/:uploadId`
Retrieve the generated JSON metadata for an upload.

**Response**: JSON metadata object

### GET `/api/uploads`
Get a list of all uploads.

**Response**: Array of upload objects

### GET `/api/health`
Health check endpoint.

**Response**: Server status

## S3 Bucket Structure

```
your-bucket/
├── auditors-report/
│   ├── uploads/       # Uploaded documents (uploaded by this app)
│   │   └── {upload-id}.{ext}
│   └── json/          # Generated JSON files (created by your pipeline)
│       └── {upload-id}.json
```

## JSON Metadata Format

The JSON generated by your pipeline is fetched from the `auditors-report/json/` folder. The format depends on your existing pipeline implementation. The application will display whatever JSON structure your pipeline generates.

## Troubleshooting

### Common Issues

1. **AWS Credentials Error**
   - Verify your `.env` file has correct AWS credentials
   - Check that your AWS user has S3 permissions

2. **CORS Issues**
   - Backend has CORS enabled for localhost:3000
   - Check browser console for specific CORS errors

3. **File Upload Fails**
   - Check file size (10MB limit)
   - Verify file type is supported
   - Check backend logs for detailed error messages

4. **JSON Not Found**
   - Wait for processing to complete (usually 1-2 seconds)
   - Check that the upload status is "completed"
   - Verify the upload ID is correct

### Environment Variables

Required environment variables in `backend/.env`:

- `AWS_ACCESS_KEY_ID`: Your AWS access key
- `AWS_SECRET_ACCESS_KEY`: Your AWS secret key
- `AWS_REGION`: AWS region (default: us-east-1)
- `S3_BUCKET_NAME`: Your S3 bucket name
- `PORT`: Server port (default: 5000)
